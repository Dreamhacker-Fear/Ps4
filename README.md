# PS4 Dashboard

PS4 Dashboard is a PlayStation 4-inspired interface for Roblox. It recreates the look and feel of the PS4 home screen in a Roblox GUI, with a console-style layout, navigation, and visual elements inspired by the PlayStation interface.

## Load

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Dreamhacker-Fear/Ps4/refs/heads/main/ps4.lua"))()
```
