## Security

The copied source contains Discord webhook URLs. Because this is a client-side script and the backup repository is public, treat those webhook URLs as exposed and rotate them in Discord. Do not use client-side webhook URLs for private channels or trusted actions; route posting through a secure server-side service instead.

## Testing

The file replacement was verified against the source file. This confirms the GitHub contents match; it does not confirm the script has been runtime-tested in Roblox.
